# Прецедент UC-1: Добыть звёздную пыль (клик по ядру)

* **Актёр:** Игрок (Player)
* **Краткое описание:** Игрок нажимает центральную интерактивную кнопку кузницы звезды для активного получения звёздной пыли.
* **Предусловия:** Приложение запущено, активна вкладка «Игра» (`GamePanel`).

### Основной поток событий (Basic Flow)
1. Игрок нажимает левой кнопкой мыши на кнопку «КЛИК!».
2. Виджет `ClickButton` генерирует событие и передаёт управление в `GameController.onClick()`.
3. Контроллер вызывает метод `GameModel.click()`.
4. Модель увеличивает текущий баланс `dust` и показатель `totalEarned` на величину `clickPower`, инкрементирует `totalClicks`.
5. Модель проверяет выполнение предикатов достижений (`Achievement.isReached()`).
6. Модель оповещает подписчиков через вызов `ModelListener.modelChanged()`.
7. Представление `MainFrame` синхронно перерисовывает счётчик ресурсов и прогресс-бар опыта.

### Альтернативные потоки (Alternative Flows)
* **А1 (Бонус Золотой звезды активен):** На шаге 4, если в модели действует временный множитель от события Golden Star, начисленная сумма пыли умножается на величину бонуса, а интерфейс отображает золотое свечение.
* **А2 (Разблокировка достижения):** На шаге 5 предикат достижения возвращает `true`. Модель вызывает `ModelListener.achievementUnlocked()`, интерфейс отображает всплывающее уведомление и воспроизводит победный звук.

* **Постусловия:** Баланс звёздной пыли игрока увеличен, интерфейс актуализирован.
