# Глоссарий проекта StarForge Clicker

| Термин (EN / RU) | Определение и контекст использования |
| :--- | :--- |
| **Звёздная пыль (Stardust)** | Основной количественный игровой ресурс (валюта), добываемый активными кликами по центральной звезде и пассивными генераторами. Служит для покупки улучшений. |
| **Сила клика (Click Power / SPC)** | Объем звёздной пыли, начисляемый на баланс игрока за одно физическое нажатие кнопки мыши на экране кузницы звезды. |
| **Доход в секунду (Passive Income / SPS)** | Суммарный объем звёздной пыли, автоматически начисляемый модели каждую секунду. Формируется работой генераторов (буров, добытчиков, реакторов). |
| **Тик времени (Game Tick)** | Дискретный шаг игрового таймера равный 100 мс (0.1 с), вызывающий пересчёт баланса и проверку достижений без блокировки графического интерфейса. |
| **Золотая звезда (Golden Star)** | Случайное интерактивное событие, визуализируемое на ограниченное время (~10 с), клик по которому приносит мгновенный бонусный множитель ресурсов. |
| **Галактический Престиж (Galactic Prestige)** | Механика сброса накопленной базовой пыли и уровней построек в обмен на престиж-валюту («Тёмную материю»), дающую постоянный глобальный множитель. |
| **Тёмная материя (Dark Matter)** | Постоянная валюта мета-прогрессии, начисляемая при выполнении престижа по степенной формуле от суммарно добытой за всё время пыли. |
| **Поток событий (Event Dispatch Thread, EDT)** | Выделенный системный поток Java Swing, в котором выполняются обработка пользовательского ввода, отрисовка компонентов и тики таймеров. |
| **Паттерн MVC (Model-View-Controller)** | Архитектурный шаблон разделения ответственности: GameModel (данные и бизнес-правила), View (панели Swing), GameController (обработчики действий). |
| **Офлайн-доход (Offline Earnings)** | Расчетная сумма ресурсов, начисляемая игроку при запуске приложения за время отсутствия (с ограничением до 8 часов и эффективностью 50%). |
