# Прецедент UC-2: Купить улучшение / постройку

* **Актёр:** Игрок (Player)
* **Краткое описание:** Игрок приобретает очередное улучшение силы клика или генератор пассивного дохода за звёздную пыль.
* **Предусловия:** Открыта панель быстрой покупки на главном экране или вкладка «Улучшения».

### Основной поток событий (Basic Flow)
1. Игрок нажимает кнопку «Купить» напротив выбранного улучшения (`Upgrade`).
2. Представление передаёт запрос `GameController.onBuy(upgrade)`.
3. Контроллер вызывает `GameModel.buy(upgrade)`.
4. Модель рассчитывает цену `cost = ceil(baseCost * 1.15^level)` и проверяет условие `dust >= cost`.
5. Модель вычитает `cost` из `dust`, увеличивает `level` улучшения на 1.
6. Модель пересчитывает производные параметры (`clickPower` или `dustPerSec`).
7. Модель оповещает представление через `modelChanged()`.
8. Воспроизводится аудиоэффект покупки, обновляются надписи уровней и цен.

### Альтернативные потоки (Alternative Flows)
* **А1 (Недостаточно пыли):** На шаге 4 баланс `dust < cost`. Модель возвращает `false`, состояние не изменяется. Воспроизводится звук ошибки, покупка блокируется.

* **Постусловия:** Уровень улучшения увеличен, баланс пыли списан, доход возрос.
